# Nearby Places

آس پاس کے علاقوں کے نام، فاصلہ اور سمت دکھاتی ہے، انٹرنیٹ کے بغیر بھی۔

## ایپ کیا کرتی ہے
- موجودہ مقام (عرض بلد/طول بلد)، درستگی، بلندی، رفتار، اور کمپاس کی سمت (مثلاً شمال مشرق 45°)۔
- 40 قریب ترین مقامات: نام، فاصلہ، سمت اور گھومتا ہوا تیر جو فون گھمانے پر درست سمت دکھاتا ہے۔
- آف لائن: پاکستان، افغانستان، خطے اور دنیا کے اہم شہروں کی بلٹ اِن فہرست۔
- آف لائن کے لیے اضافہ: انٹرنیٹ ہو تو OpenStreetMap سے آس پاس کے شہر/قصبے/گاؤں خود محفوظ ہوتے ہیں (یا بٹن دبائیں)، پھر وہی بغیر انٹرنیٹ دکھتے ہیں۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `NearbyPlaces-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں۔
- بلٹ اِن فہرست میں مقامات کے نقطے تقریباً ہیں اور فہرست مختصر ہے؛ چھوٹے گاؤں کے لیے ایک بار انٹرنیٹ سے علاقہ محفوظ کرنا ضروری ہے۔
- فاصلہ سیدھی لکیر میں ہے، سڑک کا نہیں۔
- ڈاؤن لوڈ کے وقت آپ کا مقام OpenStreetMap کے سرور کو جاتا ہے؛ سیٹنگز میں خودکار ڈاؤن لوڈ بند کر سکتے ہیں۔
- کمپاس کے لیے فون میں rotation سینسر ہونا چاہیے؛ نہ ہو تو سمت شمال کے حساب سے دکھتی ہے۔
